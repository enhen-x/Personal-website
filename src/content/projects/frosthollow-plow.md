### 一、项目简介

**霜谷铲雪社（Frosthollow Plow）** 是一款治愈系 3D 等距视角铲雪小游戏。玩家驾驶高山铲雪车穿行于北欧暮色雪村，在温暖亮灯的木屋与路灯暖光池之间推开松软积雪、救援被大雪掩埋的信箱、串联暖心连击倍率，并在霜谷车库中持续改装升级自己的爱车。

整个项目的 3D 低多边形组合模型、Canvas PBR 纹理、地面光晕以及所有音频反馈均由代码程序化实时生成，无需额外外部音画资源即可在浏览器中直接运行。

---

### 二、核心特色

- **实时 3D 积雪网格与铲雪物理**：基于 `52×52` 确定性雪层网格，雪铲推过时实时压低路面积雪、露出鹅卵石道路，并在两侧堆起自然雪堤，伴随飞溅雪花粒子效果。
- **三条风情各异的小镇路段**：随班次进度逐一解锁，每张地图包含独立路网、温暖亮灯的木屋、路灯暖光池、地标建筑（钟楼 / 喷泉 / 凉亭）及雪埋信箱。
- **连击倍率与信箱救援**：连续清雪不断叠加连击倍率，触发五声音阶递进音效与飘字提示；清出路边被雪埋住的信箱可获额外金币奖励，达成 100% 完美清雪更有额外加成。
- **霜谷车库永久升级系统**：5 类可升至 5 级的改装项，升级与金币自动持久化至 `localStorage`，跨路段永久保留。
- **零外部素材的程序化音频引擎**：基于 Web Audio API 实时合成发动机低鸣、铲雪沙沙声、五声音阶连击提示音、信箱救援音效、涡轮加速声、升级和弦与完工欢呼。
- **原生中英文双语切换（默认简体中文）**：支持在标题页、局内 HUD 及暂停界面一键切换中/英文，切换过程不会重置 3D 场景与局内进度，并自动记忆语言偏好。

### 三、小镇路段

| 路段名称 | 路段简介 |
| --- | --- |
| 1 · **松溪大道** (Pinebrook Lane) | 在晨间热可可出炉前，清理村镇主道与钟楼广场。 |
| 2 · **灯笼广场** (Lantern Square) | 昨夜大雪掩埋了双环集市与面包房巷道。 |
| 3 · **林岭雪道** (Timber Ridge Pass) | 厚实的粉雪覆盖了节日林荫大道与山脊弯道。 |

### 四、霜谷车库升级

| 升级项（最高 Lv.5） | 效果说明 |
| --- | --- |
| **宽幅高山雪铲** | 加宽铲刃与侧翼挡板，单趟即可扫出更宽阔的石板路。 |
| **冬日扭矩引擎** | 提升行驶速度与推雪动力，轻松冲破厚重雪堆。 |
| **加热黄铜铲刃** | 顺畅融化密实积雪，并提高每片清雪的金币收益。 |
| **连击保温器** | 延长连击保持时间，并解锁更高的连击倍率上限。 |
| **热可可蒸汽涡轮** | 扩充涡轮燃料箱并加快充能，随时开启强力冲刺清雪。 |

### 五、操作方式

| 按键 / 交互 | 功能 |
| --- | --- |
| `W` `A` `S` `D` 或 方向键 | 驾驶与转向 |
| 鼠标左键按住并拖动 | 朝光标方向平滑转向驾驶 |
| `Space`（空格键） | 开启热可可蒸汽涡轮加速 |
| `Q` / `E` 或 鼠标滚轮 | 缩放等距视角镜头 |
| `U` | 打开 / 关闭霜谷车库升级界面 |
| `P` 或 `Esc` | 暂停 / 继续当前班次 |
| `M` | 静音 / 开启合成音效 |

### 六、技术栈

- **前端框架**：React 19 + TypeScript + Vite 8
- **3D 渲染**：Three.js（等距正交相机、程序化低多边形组合模型与 Canvas PBR 纹理、软件 WebGL 自适应优化）
- **样式系统**：Tailwind CSS v4
- **音频系统**：原生 Web Audio API 程序化合成器
- **测试工具**：Node.js 内置测试运行器（`node:test` + `tsx`）
