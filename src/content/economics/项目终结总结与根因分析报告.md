# Executive Summary

本项目在 2026-03 出现显著 Alpha Decay：月度收益 **-11.30%**、胜率 **33.33%**，累计收益从 **+13.03%** 快速回落至 **+0.24%**。综合证据表明，本次失利不是单一黑天鹅所致，而是 **Regime Shift 触发下，风格暴露、风控闸门、执行摩擦三者共振** 的结果。

**口径声明**：本文仅使用仓库内事实源（`note/`、`reports/`、`config/main.yaml`）。回测口径差异（如“约-12%”与“-7.38%”）按样本区间、回测版本、统计窗口不同并列呈现，不做主观统一。

## 项目全景与构建思路（给首次阅读者）

### 构建目标与设计哲学

- **配置驱动**：统一由 `config/main.yaml` 控制，减少策略行为漂移。
- **模块解耦**：数据、预处理、模型、策略、回测、实盘、分析分层，便于独立迭代。
- **数据契约**：以 Parquet 与统一字段衔接全链路，保证上游产物可被下游直接消费。
- **可复现性**：Walk-Forward + 版本化模型产物 + 固定脚本入口。
- **研究-交易闭环**：从研究验证到实盘执行再回流复盘，持续迭代。

### 端到端流程（工程链路）

`数据获取 → 数据质检 → 特征/标签 → Walk-Forward训练 → 信号生成 → 回测验证 → 实盘执行 → 监控复盘`

![项目总流程图](/photos/经济/量化项目终结总结与根因分析报告/QUANT_A_SHARE_V2.png)

- 数据获取：`scripts/date_landing/init_stock_pool.py`、`download_data.py`、`update_data.py` → `data/raw/*.parquet`
- 数据质检：`scripts/analisis/clean_and_check.py` → 可用样本与质检结论
- 特征标签：`scripts/feature_create/rebuild_features.py` → `data/processed/all_stocks.parquet`
- 训练推理：`scripts/model_train/run_walkforward.py` / `run_inference_update.py` → `data/models/{version}/`
- 信号回测：`scripts/back_test/run_recommendation.py` / `run_backtest.py`
- 稳健性检验：`check_overfit.py`、`check_stress_test.py`、`check_monte_carlo.py`
- 实盘执行：`scripts/live/run_auto_trading.py`、`run_weekly_rebalance.py`

# Performance & Risk Attribution

1. **系统性冲击与内生失真并存**：3月收益 **-11.30%**，基准 **-5.77%**，可拆为市场下行损失（Beta）与额外失真（Alpha 失效）两部分；超额失真约 **-5.53%**，占比接近一半。
2. **风格反噬是回撤放大器**：组合长期偏“小市值+负PE”，在风险偏好切换时更易遭遇流动性折价与尾部定价重估。
3. **低胜率叠加高换手形成负反馈**：胜率降至 **33.33%** 同时交易次数 **34**、平均换仓率约 **72%**，Friction Cost 从“次要噪音”升级为“净值侵蚀项”。
4. **损失集中度偏高**：亏损 Top5 对组合拖累明显，说明单票尾部约束不足。

# Discrepancy & Overfitting Review

1. **回测-实盘断层显著**：回测 Baseline 指标高（年化 **101.92%**、夏普 **6.65**、最大回撤 **-7.38%**），但实盘累计收益仅 **+0.24%**，且3月单月回撤 **-11.30%**。
2. **历史危机覆盖不足以解释当前冲击强度**：既有危机场景回撤区间显著小于本次实盘回撤，说明测试集未充分覆盖本轮风格踩踏强度。
3. **不是“完全伪信号”但存在样本外稳定性边界**：Noise 扰动下仍有表现，Random 显著失效；问题更偏向样本外 regime 与执行/风控链路失配。
4. **双头模型未形成风险闸门闭环**：风险头参与了评分，但未在极端阶段有效转化为“降仓/收敛暴露”的执行动作。

# Root Causes of Failure

1. **战略级失效（Alpha Source Concentration）**

- 根因：Alpha 过度依赖小盘反转/困境修复风格，缺乏跨风格冗余。
- 后果：Regime 切换时同向失效，回撤快速放大。

2. **模型级失效（Risk Head to Control Gap）**

- 根因：风险预测未闭环到强约束执行，风险头“看见风险”但系统“没真正刹车”。
- 后果：危机期未及时降暴露或收仓位。

3. **风控级失效（Tail-Risk Budget Missing）**

- 根因：单票硬止损、单票回撤贡献上限、组合熔断机制不充分。
- 后果：亏损集中度高，尾部风险非线性侵蚀净值。

4. **执行级失效（Turnover-Threshold Mismatch）**

- 根因：阈值宽松与高换手并存，导致无效调仓和成本拖累。
- 后果：净Alpha被Friction Cost持续压缩。

# Action Plan for V3.0

1. **策略层（风格再平衡）**

- 增加质量/基本面硬过滤，压降负PE与超小市值暴露。
- 构建跨风格冗余（质量、低波、盈利稳定性），设置风格暴露上限。
- 目标指标：`负PE占比`、`<30亿占比`、`风格暴露集中度`。

2. **模型层（双头到闸门）**

- 将风险头输出升级为硬交易约束（高风险分位降权/剔除）。
- 在高波动 regime 提高 risk aversion，形成动态防守。
- 目标指标：`高风险分位持仓占比`、`risk_head 命中率`、`降仓响应速度`。

3. **风控层（硬约束）**

- 上线单票风险预算、分层止损、组合回撤熔断。
- 强制监控单票回撤贡献与亏损集中度。
- 目标指标：`Top5亏损集中度`、`单票回撤贡献度`、`组合MDD`。

4. **执行层（减换手、降摩擦）**

- 收紧入场阈值与最小信号差，提升持仓重叠约束，减少无效轮动。
- 把交易成本前置到目标函数（净Alpha优化）。
- 目标指标：`平均换仓率`、`单次调仓净收益`、`成本拖累率`。

5. **评估层（统一口径与复盘工程化）**

- 固化样本区间、成本口径、回测版本、持仓周期，确保可比性。
- 月度固定输出：风格暴露上限、尾部贡献度、成本拖累率。
- 目标指标：`口径一致性通过率`、`Backtest-Live 偏差监控`。
